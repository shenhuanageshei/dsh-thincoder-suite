**双层形态（这是防漂的核心）**：

|---|---|---|---|
| **规范层** | `METHODOLOGY.md` 新子节 | 七条**现在时态的规范性条文**，逐条 1–3 句；**零状态句、零聚合计数**（绝不出现「现有 N 条 / 部分 M 条」） | **规范句不含经验断言 ⇒ 不会漂** |

### ② D6 回读核对：覆盖两面 + 三谓词 + 一条禁令

**覆盖面 = 代码面 + 文档面，不做区分**。三次实证横跨两面（METHODOLOGY 被截为 1 行 = 文档面；PowerShell 双编码对 CJK 最致命 = 两面；U+FFFD = 两面）⇒ 只罩代码面会把**最狠那次**留在网外。

**条文**：「任何写入/编辑报成功后，必须**用读工具回读被改区域**，确认三点再报完成：① 预期改动在回读内容中；② U+FFFD 计数为 0；③ 行数变化与本次改动的**预期增删**一致（意外塌缩 = 异常）。**回读不得使用刚执行写入的同一条 shell 管道**。**结构性改档用编辑工具，禁 shell 单行脚本整档重写**（批 8 截断事故）。回读未见改动 = 写入静默失败 ⇒ 按失败路径报告，**不得重报成功**。」
- 判据可执行性：①② 是字面断言；③ 的判据是「预期增删」而**非固定阈值**（「降幅 >50%」之类是伪精确——删档型改动会误伤）。
- 「禁同一管道」封掉已实证的**假回读**路径（harness 实测 `(Get-Content).Count` 会低报）。

**机械层（用户裁定 = 建新档，两项都做）**：新建 **`test/doc-hygiene.test.mjs`**：

### ③ 失败路径两条：**双落点，分工写死**

**分工原则：能放进返回串的绝不放进提示词**——返回串是**机锁面**（字串断言可测），提示词是**行为面**（模型遵守不可机验）。本批只吸收两条，那就让两条都在机锁面有锚。

**(a) 工具返回值 `lib/eng.mjs`（主落点，机械、必然触发）**：新增一个**共享后缀函数**，追加到**全部终态执行失败**返回点的 output 尾部。
- **形态 = 出口边界后处理，否决逐站点改 17 处**（必漏 + churn）。**实施 stage 0 先读代码确认是否存在单一出口边界**；若 codex/dsh 两族各有边界则两个挂点，仍远优于 17 处。
- **不改 `deathLine` 格式**（被 death-provenance 18 例锁、且该档是 **R0 不可入授权面**）⇒ 块只能**追加在既有字串之后**，`includes` 断言全保持绿。
- helper **必须放在 `stageGateNote`→`makeWriteGate` 切片之外**（`stage-gate.test.mjs:238-239` 锁该段函数体）。
- **不做** `stalled` 终态（status 仍 `failed`）· **不动**「失败不簿记」· **不加**阶段门横幅到失败路径。

**后缀内容（固定字面 · ★ 设计评审轮次 1 订正后的权威字面，以设计档 §6.2 为准）**：停下向用户报告——**不自动重派**，由用户裁决。报告须含：崩在哪一步（见 detail）/ 工作区已改了什么（见 partial 与 Touched advisory）/ 任务哪部分未动。可选项：**① 原样重派（同 token，若仍有效）② 带半成品继续 ③ 清理工作区后重来（必要时 git 回滚）④ 改道（换执行通道或策略）⑤ 作废本链**。
> **两处订正的来由**（评审轮次 1）：① 原写「同 token——**token 未消费**」并**对所有失败种类统一断言**，而「token is not consumed」在 `index.mjs:937` **只针对自报阶段失败**那一类 ⇒ **会输出假事实**，已改弱为「若仍有效」；② 原写「Touched **提示**」，而 `codex-runner.test.mjs:4037` 的禁令字面是 **`Touched 行`（带「行」字）**，裸词 `Touched` 不禁 ⇒ 已改为「Touched advisory」（**不含**禁字面）。
- **用户裁定 = 五项**（上游四项 + **改道**）。**改道的必要性经实测**：批 10 的 codex **连续两次 `PROCESS_ERROR`**，四项里**没有一项对症**（重派会用同一坏通道再死一次，其余三项不对症）；批 9 会诊的 codex 失败同形态。上游四项穷尽了「工作区 × 任务」的积空间，**但穷不尽「通道」这一维**。
- **字节雷区**：后缀**不得引入字面 `Partial output`**（`codex-runner.test.mjs:4037` 反向断言）；不得在失败行引入 `stageGateNote` 字样（`stage-gate.test.mjs:118` 的源码扫描）。

**适用边界（防过用）**：只罩**运行中子代理的异常终态**（failed / abort / timeout，codex 与 dsh 两族、bg 与 sync 两路）；**不罩**预检拒绝（in-flight job、token 过期/不匹配、task 缺失——**工作未发生**，自带补救指引，可选项不同）。

**(b) 主代理提示词 `lib/prompts/engineering.md`（副落点，政策）**：在既有「advisor 失败 ⇒ stop and report」句旁，加 eng_coder 版平行一句：**自含、无 `METHODOLOGY` 指涉**（T-PK15）。

**(c) 边界句 `lib/index.mjs:937`（必须同批落地，否则两条纪律互相矛盾）**：该句现写「stage 失败 ⇒ 重派一个（token 未消费）」——这是**现行的自动重派指令**，与新纪律张力明显。裁定：**保留该授权但划界**——该授权**仅限「子代理自报的阶段失败且报告完整」**（出口干净、工作区可检）；**崩溃 / 超时 / abort 不自动重派**，停下报告可选项清单由用户裁决。已 grep 实证该串**无任何测试断言**。
