## Q1：「同一可数事实」的机械可识别定义

### 先评估三个候选

**(i) 事实 id（`（N 项 id=负控构造：…）`）**——分组机制对，但**按你给的形态单独使用有一个可证明的 fail-open 缝**：

> id 笔误会把「同一事实的两处出现」切成**两个单例组**。单例组内部永远自洽（一个值跟自己比）⇒ 谓词判绿。也就是说：**候选 (i) 恰好在「作者改了一处、顺手把另一处的 id 打错」这种最接近真实事故的操作下静默失效**。P-1（A10 行宣称已改而未改）的变异形态就是它。

修复办法是给每个 id **钉死期望出现次数（arity）**：`负控构造 = 8 · 出现 4 处`。于是任何 id 漂移 ⇒ 出现数 ≠ arity ⇒ 红。这一步把 (i) 从「分组比对」升级成「登记 + 比对」，fail-open 缝闭合。

**(ii) 单一权威表**——与仓里 D2（单一权威源）同构，作为**写作纪律**是对的；作为**谓词机制**不可行，因为至少两个面**必须**字面携带值：CHANGELOG 计数行（`parseChangelogCountLine` 的契约就是读字面 `**N/N**` + `基线 X` + `本批 Y`，release-check.mjs:59-71）和台账 §三（T-LC2 等值锁的两侧都是从文档字节读）。值不许重复的地方才不需要比对；**值必须重复的地方，比对是唯一手段**。(ii) 管不了这些面。

**(iii) 成对枚举**——批 16 腿 2 已是这个形态（`compare: §11.2:§11.3`），它的问题是 O(n²) 声明、每加一处出现要改声明、且只做集合不做标量。**维持现状，不扩展**——它已经覆盖了它擅长的那一类（AC 号集 ↔ 分层表）。

### 我的推荐：**登记行 + 双提取方言**

**定义（机械可执行的）**：一个「可数事实」= 登记行里的一个条目，形如 `事实id : 值 : 元数`。谓词对每个事实id执行两条不变量：

1. **同值不变量**：该 id 的全部出现，归一化后的值相等（枚举型比对 `·` 项集合，标量型比对字面——数字/SHA/semver）；
2. **元数不变量**：该 id 的实际出现数 == 登记的元数（多、少都红）。

**两种提取方言（同一个登记行，两种取值来源）**：

- **方言 A（档内标记）**：扩展现有腿 1 标记，`（8 条 id=负控构造：a · b …）`——括注本来就是自然中文，追加 id 段不破坏可读性（批 16 D16-1 成功的原因就是「自然阅读顺序里就有意义」，沿用）。
- **方言 B（固定面字面绑定）**：CHANGELOG 这类**形状本身就是标记**的面，不需要也不应插入 id 标记（见 Q3），而是登记行里声明绑定规则：`本批新增 → CHANGELOG 首节的「本批 N」字面`。提取器按绑定规则取值，算作该事实的一次出现。**固定面的形状是仓自有的、已解析器化的——「只认显式标记」的约束管的是散文猜测，不管结构面**。62% 误报教训杀死的是正则猜中文量词，不是解析表格和计数行。

**登记行住哪**：本批设计档的 `doc-shape` 声明扩展一个键（如 `facts:`），**跨文件事实（如 P-3 的需求档↔设计档）用全局 id 命名空间**（建议带批前缀，如 `批16.负控构造`），arity 只允许在**一个**档里登记——两处登记同一 id ⇒ 红。这直接覆盖 P-3/P-4 那种跨档漂移。

## Q3：与 CHANGELOG 既有契约共存

## Q4：fail-closed vs 存量全红——这个张力是伪的

张力只在「作用域成员资格」与「作用域内判定」被混成一谈时存在。拆开：

- **作用域内，全 fail-closed**（不变）：登记的事实提取零出现 ⇒ 红（元数不变量）；绑定面定位不到 ⇒ 红；空扫描集 ⇒ 红（`scanned >= 1` 沿用）。
- **成员资格本身是被检查的事实**：日期 ≥ 截止日而无声明 ⇒ 红（Q2 第二层）；固定面缺席（CHANGELOG 无计数行）⇒ 既有 G3 红 + 新腿红。于是「没声明就红」**只对应当滚入而未滚入的新档**，存量档根本不在判定的左真值表里——不存在「存量全红」的分支。

**负控腿清单（每条都要真红 + 阴性对照，纯内存/临时副本，沿 D5）**：

1. 同 id 两处异值 ⇒ 红（同值不变量）；
2. id 笔误 ⇒ 单例 + 元数缺额 ⇒ 红（**这条是证明 fail-open 缝已闭合的关键腿**，对应候选 (i) 的缺陷）；
3. 出现数多于元数 ⇒ 红（防「复制粘贴多一处」）；
4. 日期 ≥ 截止日无声明 ⇒ 红（+ 阴性：09-16 存量档无声明 ⇒ 不红）；
5. CHANGELOG 首节第二条推导式 ⇒ 红（+ 阴性：恰一条 ⇒ 不红）；
6. 变异自证沿仓例：把元数判据退化成 `>=1` ⇒ 腿 2 红；把截止日改成昨 ⇒ 存量全红即证明该腿绑的是「滚入」性质。

**最后一个必须写进设计档的风险（批 16 审计核心批评的复发面）**：批 16 两档自己的标记**全部写在代码 span 内**（负控腿 1 的注释自己承认这点），负控只能在临时档构造——「一个抓文档形状缺陷的机器，两条腿在真档上零作用域」。批 17 若照抄这个写作习惯，新腿又会是「只在夹具上活过」。**设计档必须规定：批 17 自己的事实出现写在代码 span 之外的正文/表格里，且验收含「每条新腿在 ≥1 个真实面实跑」的断言**（批 16 已有 `leg4Runs >= 1` 先例，扩展到新腿）。这不是锦上添花——它是「作用域与宣言对齐」这句批题在批 17 自己身上的兑现。

## Q1：「同一可数事实」的机械定义

对三个候选的裁决：

| 候选 | 裁决 | 理由 |
|---|---|---|
| (iii) 成对枚举 | **否决** | 无 id 的「成对枚举」= 靠形态相似性猜「哪几处是同一事实」= 正则猜的变体（62% 误报同族）。带 id 的成对枚举就是 (i)。 |
| (ii) 单一权威表 + 指针 | **部分采纳，作报告惯例而非判据** | 指针本身不可机械验值：验「指针指向的节存在」= 既有腿 3；验「指针指向处的值」⇒ 那处必须有标记 ⇒ 退化成 (i)。但它与 **D3（「一个数只设一个权威自报点，他处用指针」）同源**——保留为写档纪律，红时报错点出全部出现处即可，不必在语法里树「权威」。 |
| (i) 事实 id | **采纳为核** | 唯一能让机器免猜地分组的手段。 |

**(i) 的关键是堵它自己的三个 fail-open 缝**，堵法决定了机制成立与否：

1. **id 拼错 ⇒ 静默裂组**（两处本是同一事实，id 差一字 ⇒ 永不比对 ⇒ 静默绿）。**堵法：自声明 id + 单例必红**——任何带 `id=` 的标记都是一句声明「这个事实在别处也出现」；分组后**单例（全仓仅 1 次出现）⇒ 红**。拼错的 id 必然形成单例 ⇒ 当场被抓。这一条同时免掉「事实 id 注册表」（不必在声明头列 id 清单），机制显著变简。
2. **只出现一次的事实**——单例必红会误伤「本来就只写一次的数」。**堵法：约定纪律**——id 只标「多处出现的事实」；单写一次的数不标 id。误标 = 单例红 = 可见、可纠。
3. **删掉 id 逃比对**——删 id 后该处退回普通计数/散文。**堵法：与 Q2 的「自识别腿常开」合流**：即使删 id，只要那处还是 `（N 项：…）` 标记形态，腿 1 的项数核对仍在跑；退回纯散文计数才是真逃逸，那是 N-1 的**残差边界**（见文末），必须如实写进设计档，不假装堵住了。

**语法与集成的具体形态**（与腿 1 共用一个匹配器，避免两套正则漂移）：

```
腿 1 现正则： （([0-9]+)\s*(量词)：
扩展为：     （([0-9]+)\s*(量词)(?:\s+id=[^\s：）]+)?：
纯计数形态： （([0-9]+)\s*(量词)\s+id=[^\s）]+）     ← 无冒号、无列表，值 = N
```

- **腿 1 与事实腿共用一个匹配器**：腿 1 对全部命中数 `·` 项（带不带 id 都数——今天 `（8 条 id=b17-x：…）` 形态**对现腿 1 正则不可见**，这正是集成时要修的点）；事实腿只对带 `id=` 的命中做分组。
- **分组比对的三个值**：计数 N（各出现处相等）· 枚举项集合（有列表的形态，集合相等——补 P-6「枚举 8 项却断言 9 条」的跨位置形态）· 出现处数 ≥ 2。
- **比对域**：跨档——`docs/**/*.md` ∪ `CHANGELOG.md`。id 约定批次前缀（`b17-…`）防跨批撞名；撞名且值不等的失败形态是**假红**（可见、改 id 即解），方向正确。
- **报错**：组内任一处不等 ⇒ 报**全部出现处的 文件:行:值**（US-2 的「报出全部出现处」）。
- **空集方向**：全仓 ≥1 个「≥2 出现处的组」断言在位（`scanned >= 1` 的同族，防恒真）。
- **残差边界（必须明写）**：P-2 那种「订正语留在列表格里」——标记段落内的 `·` 项含 `订正|初写|原写` 字样可加一条窄腿（只在计数标记段内扫，仓内零存量命中面需实测），但「散文里的计数」永不可机械覆盖。**这是本机制的天花板，设计档应把它写成一条显式边界，而不是让评审去发现。**

## Q1：「同一可数事实」的机械定义 —— 三候选评估与我的方案

### 三候选评估

| 候选 | 判定 | 理由（全部回盘核过） |
|---|---|---|
| **(iii) 成对枚举** | **作为通则最差，否决** | 它把同一事实的完整副本数最大化 ⇒ **编辑点最大化 = 漂移面最大化**。批 16 的 62% 误报实测与「改两处之一不算修好」的五次复发共同指向一条：**重复是敌人**。它只在「短而结构化」的集合上成立——而那就是腿 2 的 `compare`（AC 号集），已经存在，不用新造 |

### (i) 必须补上的四个设计点（缺一就会再逃一次）

**① 两种出现形态。** 在腿 1 既有标记上扩语法（id-less 旧标记保持合法，N-3 零回归）：

- **全枚举形态**（扩腿 1）：`（8 项 id=负控构造：腿1 · 腿2 · … · 腿8）`——既做腿 1 的「N == 本行 `·` 项数」，又把**集合**登记到 id 下；
- **裸引用形态**（新增）：`（8 项 id=负控构造）`——无枚举，只把**标量**登记到 id 下。

id 字符集建议 `[^\s（）：·]+`（CJK 合法，`负控构造` 这种 id 读着就是自然中文）。**只有一处需要写全枚举，其余处只写 N+id——把重复压到最小**，这是对 (iii) 的修正。

**② 类型化事实值 + 全局命名空间。** 事实值三型：**标量**（计数/版本号/SHA）、**标记集**（枚举项）、**键值对集**。等值规则：同 id 的全部标量相等；全部集合相等；混合形态时标量 == |集|。**id 命名空间默认跨全扫描域**（不是在单档内分组）——因为六次逃逸里 P-3/P-4/P-5 全在**跨档**处发生；档内两处作者自己看得见，跨档才需要机器。碰撞纪律：**id 带批次前缀**（如 `b17-全量用例数`）；谓词无法区分「撞名」与「有意同一」——id 相同即断言同一，不同事实就必须起不同 id，这是诚实且可执行的口径。

**③ 键值对集 = 腿 2 的一般化（这是抓 P-2 的关键）。** 腿 2 今天只比「AC 号集」。P-2 的事实是「每条 AC 的层标」——§10.2 分层表与 §10.3 层列是同一事实的两处。**把集合元素从 `AC-n` 推广到 `(AC-n, 层标)` 对**，两侧各抽 (key,value) 对集比对，P-2 的形态（订正语留在列表格里 ⇒ 机器读到字面 token）就会在抽取层直接暴露：被污染的 cell 抽出的对与另一侧不等 ⇒ 红，且报出全部出现处。

### 第二层：面级 —— 声明的默认面清单（结构触发 ⇒ 必选键，fail-closed）

- **机制**：已声明档内，**结构可检的面自动成为义务**：档内出现「首列 cell 匹配 `AC-\d+` 的表」且出现「首列匹配 `A\d+` 的表」⇒ `anchors`/`acs` 两键**必填**，缺即红。这是结构检测（不是中文猜测，N-1 兼容）。

### 第三层：事实级 —— require-facts（声明新键）+ 批次模板

## Q1：「同一可数事实」的机械定义 —— 三候选评估与我的方案

### 三候选评估

| 候选 | 判定 | 理由（全部回盘核过） |
|---|---|---|
| **(iii) 成对枚举** | **作为通则最差，否决** | 它把同一事实的完整副本数最大化 ⇒ **编辑点最大化 = 漂移面最大化**。批 16 的 62% 误报实测与「改两处之一不算修好」的五次复发共同指向一条：**重复是敌人**。它只在「短而结构化」的集合上成立——而那就是腿 2 的 `compare`（AC 号集），已经存在，不用新造 |
| **(ii) 单一权威表 + 指针** | **方向对，但作为机制与 (i) 同构** | Markdown 没有活引用——指针处**仍然要写那个数**（读者要看见值），所以谓词校的还是「两处各写一个值、必须相等」，与 (i) 完全相同。「权威」多出的只是一个**指定动作**，对校验零增益。**但「权威」要作为写侧纪律保留**（D2/D3 已有：一个数只设一个权威自报点）——它是「先改哪处」的政策，不是「怎么比」的机制 |
| **(i) 事实 id** | **采纳为核心** | 直接回答「哪几处指同一事实」：**id 即「同一性」的断言本身**，作者写下 id 就是声明同一，谓词按 id 分组比值。无歧义、可机检、与 N-1 兼容（id 住在显式标记内，不猜中文） |

### (i) 必须补上的四个设计点（缺一就会再逃一次）

**① 两种出现形态。** 在腿 1 既有标记上扩语法（id-less 旧标记保持合法，N-3 零回归）：

- **全枚举形态**（扩腿 1）：`（8 项 id=负控构造：腿1 · 腿2 · … · 腿8）`——既做腿 1 的「N == 本行 `·` 项数」，又把**集合**登记到 id 下；
- **裸引用形态**（新增）：`（8 项 id=负控构造）`——无枚举，只把**标量**登记到 id 下。

id 字符集建议 `[^\s（）：·]+`（CJK 合法，`负控构造` 这种 id 读着就是自然中文）。**只有一处需要写全枚举，其余处只写 N+id——把重复压到最小**，这是对 (iii) 的修正。

**② 类型化事实值 + 全局命名空间。** 事实值三型：**标量**（计数/版本号/SHA）、**标记集**（枚举项）、**键值对集**。等值规则：同 id 的全部标量相等；全部集合相等；混合形态时标量 == |集|。**id 命名空间默认跨全扫描域**（不是在单档内分组）——因为六次逃逸里 P-3/P-4/P-5 全在**跨档**处发生；档内两处作者自己看得见，跨档才需要机器。碰撞纪律：**id 带批次前缀**（如 `b17-全量用例数`）；谓词无法区分「撞名」与「有意同一」——id 相同即断言同一，不同事实就必须起不同 id，这是诚实且可执行的口径。

**③ 键值对集 = 腿 2 的一般化（这是抓 P-2 的关键）。** 腿 2 今天只比「AC 号集」。P-2 的事实是「每条 AC 的层标」——§10.2 分层表与 §10.3 层列是同一事实的两处。**把集合元素从 `AC-n` 推广到 `(AC-n, 层标)` 对**，两侧各抽 (key,value) 对集比对，P-2 的形态（订正语留在列表格里 ⇒ 机器读到字面 token）就会在抽取层直接暴露：被污染的 cell 抽出的对与另一侧不等 ⇒ 红，且报出全部出现处。

**④ 单例 id 的 typo 逃逸与 @N 锁（这是 (i) 最大的暗坑，必须写进设计档）。** id 打错一个字符 ⇒ 一个事实裂成两个各只出现一次的组 ⇒ **无组可比 ⇒ 静默漏报**。堵法：require-facts 声明里带出现次数锁（形如 `require-facts: b17-全量用例数@3`），该 id 出现次数 != 3 ⇒ 红。非注册事实的单例 id 不红（一次事实只出现一次是常态）——**@N 只锁注册事实**，这个不对称是有意的。

## Q2：堵「不声明就逃出作用域」—— 三层，缺一不可

先指出一个定性：**六次逃逸不全是「不声明」**。批 16 两档都声明了，逃逸发生在「事实未标记」（P-6 的散文 9 条）与「档外」（P-4）。所以单一招都堵不住，要三层：

### 第一层：档级 —— 批次档必须声明（用「截止日期常数」，不是白名单）

- **机制**：`docs/` 顶层、文件名匹配 `^YYYY-MM-DD-` 且日期 > **CUTOFF**（一个写在测试里的常量，如本批日期）的 `.md` 必须带 `doc-shape` 声明，否则红。
- **为什么这是 D16-2 的合法延伸而不是它否决的东西**：批 16 否决的是「全量追溯 + 白名单豁免」——**白名单会无限增长**；截止日期是**一个常数，永不增长**，且本仓批次档文件名日期前缀约定实测 100% 一致（我核了 docs/README.md 全表）。存量档日期全在 CUTOFF 前 ⇒ 零触动，N-2 成立。
- **代价**：约等于零。新增一个显式豁免形态（如声明里 `kind: memo` 或 `（豁免：…）` 标记）给未来的非批次档——**显式逃逸可见，隐式逃逸才是病**。`docs/consult-minutes/` 在子目录，R-25 的域本来就是非递归顶层 ⇒ 天然在外。

### 第二层：面级 —— 声明的默认面清单（结构触发 ⇒ 必选键，fail-closed）

- **机制**：已声明档内，**结构可检的面自动成为义务**：档内出现「首列 cell 匹配 `AC-\d+` 的表」且出现「首列匹配 `A\d+` 的表」⇒ `anchors`/`acs` 两键**必填**，缺即红。这是结构检测（不是中文猜测，N-1 兼容）。
- **堵的口**：档声明了 doc-shape 却故意不声明 anchors/acs ⇒ 腿 4 永不跑 ⇒ AC 表逃逸。
- **代价**：结构检测器可能误红——但爆炸半径**只有已声明档**（今日实测 = 2 份）；检测器自身须带负控（构造「有 AC 形表而无声明键」⇒ 红；「普通表」⇒ 不红）。

### 第三层：事实级 —— require-facts（声明新键）+ 批次模板

- **机制**：声明加一个键（批 16 §9 已预留「新增键须走设计档」——本批就是那个设计档）：`require-facts: b17-全量用例数@3|b17-本批新增@2|…`。谓词校验：每个列出的 id **至少出现 @N 次**（typo 裂组 ⇒ 次数不足 ⇒ 红）且全组同值。
- **堵的口**：「档声明了、但该标记的事实没标」——对**已知 recurring 事实**（用例数、负控构造数、基线、版本号这类每批必出现的口径集）把「忘了标」变成红。
- **代价**：canonical 事实集住**批次模板**（METHODOLOGY 或模板档），新档照抄；「模板外的事实」仍靠作者自觉——**这是诚实登记的残余口**：N-1 已证「找出未标记的散文计数」不可机械化（62% 误报），这个残余口只能由设计评审的 checklist 兜，不许声称机制兜了。
- **直接回答「默认面清单 vs 必须声明，代价各是什么」**：两个都要，它们堵的是不同的口（前者堵「档内缩作用域」，后者堵「整档不进作用域」），再加第三层堵「事实不标记」。三层的代价都已写明，全部前向生效、零追溯。

## Q3：CHANGELOG.md 共存 —— 只读事实源 + 定位器 + 等值锁

### 分工（这是「不打架」的核心）

| 面 |  owner | 校什么 |
|---|---|---|
| CHANGELOG **节内形态**（`基线 X + 本批 Y == N`、版本头） | **release-check / G-常驻3**（`test/release-check.test.mjs:67`） | **形态**——且它**故意不校数值**（`:73` 原文「数值不在此断言（自指）」） |

⇒ **加性而非重复**：G-常驻3 管「节内自洽」，新腿管「跨档同值」，两者正交。

### 机制三要件

**① 定位器（本批最大的坑，必须写进设计档）：交付时点新条目在「死区」里。** 本仓惯例（CHANGELOG.md:22 自证）：批次的 CHANGELOG 条目在交付时点**落在首个版本头之上**（等收口 bump 时才移入新 `## [x.y.z]`）。⇒ 交付时点 `parseChangelogCountLine`（`release-check.mjs:59-71`，永远只读**首节**）看到的是**上一批的数**，直接复用它会把批 17 的文档绑到批 16 的 464 上 ⇒ 必红（假红）。⇒ 定位器必须是两态的：

- **死区切片**（`# Changelog` 到首个 `## [` 之间）含 `【计数行】` ⇒ 绑定它（在飞批次）；
- 否则绑定**首节**的 `【计数行】`（已收口状态）；
- 死区含 **>1 个** `【计数行】` ⇒ 红（两批同飞不是本仓惯例，fail-closed）；找不到 `【计数行】` ⇒ 红（定位失败不是跳过）。

`【计数行】` 是批 16 条目里已在用的显式标记（CHANGELOG.md:13）——**本批把它升格为定位契约**，零新造语法，与 N-1 兼容。

**② 抽取器**：在定位到的切片上套用与 `parseChangelogCountLine` 同形的三条抽取（`**N/N**` / `基线 X` / `本批 Y`），产出 (actual, baseline, added) 作为三个事实的出现值，与 docs 侧同 id 出现值比对。

**③ 等值锁（防两个抽取器漂成两种方言）**：**当条目位于首节时**（收口后状态），doc-hygiene 的切片抽取结果**必须等于** `parseChangelogCountLine` 的输出。`release-check.mjs` 有 main-guard（`:457`），可安全 import——**不改它一个字符**（§5.1#5），只读。

**零格式变更**：CHANGELOG 的写法一个字不用改，G-常驻2/常驻3 的契约零扰动。P-4 一类（修复轮忘了 CHANGELOG）由此变红：docs 侧 id 值改了、CHANGELOG 死区里的旧值没动 ⇒ 跨档不等 ⇒ 红。

## Q4：失败方向的张力 —— 域分离，张力即消

张力的假象来自把「没声明就红」当成全域规则。正解是**两个域、一条机械边界**：

| 域 | 成员 | 失败方向 |
|---|---|---|
| **闭域（fail-closed）** | 已声明档 ∪ CUTOFF 后日期档 ∪ 登记的外部档（CHANGELOG.md） | 抽取失败 ⇒ 红 · 全域零 id 事实 ⇒ 红（D16-7 同律的零扫描闸）· require-facts 缺 id ⇒ 红 · @N 不足 ⇒ 红 · 同 id 异值 ⇒ 红 · 结构触发缺键 ⇒ 红 · CHANGELOG 定位失败 ⇒ 红 |
| **开域（fail-open，永久）** | CUTOFF 前未声明档（存量 53 档） | 跳过，永不红（N-2 / D16-2） |

**没有档能静默从闭域滑进开域**：CUTOFF 后无声明 = 红（不是跳过）；已声明档缩键 = 结构触发红；声明畸形 = 红（批 16 既有）。「没声明就红」只作用于**义务存在之处**，而义务本身是一个常数 ⇒ 存量零红，张力消解。

**负控清单**（US-5，每条新腿 ≥1 负控 + 阴性对照，全部临时副本/内存夹具，D5）：

1. 同 id 两处异值 ⇒ 红，且**报出全部出现处**（US-2 判定句）；
2. require-facts 的 id 整档缺失 ⇒ 红；
3. @N 次数不足（模拟 typo 裂组）⇒ 红；
4. 全扫描域零 id 事实 ⇒ 红（防恒真）；
5. 枚举形态 vs 标量形态，N ≠ |集| ⇒ 红（P-6 构型复刻）；
6. CHANGELOG 绑定：docs 值 ≠ 抽取值 ⇒ 红；死区多 `【计数行】` ⇒ 红；定位失败 ⇒ 红；
7. CUTOFF 后日期档无声明 ⇒ 红；
8. **变异**：把等值判定退成恒真 ⇒ 1–6 全红；
9. **阴性对照**：CUTOFF 前无声明档 ⇒ **静默跳过**；非注册单例 id ⇒ 绿；全一致 ⇒ 绿；交付时点（死区位）与收口后（首区位）两态定位**各自正确**。

## §3 分歧与父侧裁定

| # | 分歧 | 各家立场 | **父侧裁定** |
|---|---|---|---|
| **①** | **`(ii)` 单一权威表 / `(iii)` 成对枚举 该不该作机制** | [2]：`(ii)` 降纪律、`(iii)` 维持现状 · [3]：同 · [4]：`(iii)` 作通则最差（**编辑点最大化 = 漂移面最大化**）；`(ii)` 与 `(i)` **同构**（Markdown 无活引用 ⇒ 指针处仍要写值） | **两家独立同结论 ⇒ 采纳**：**`(i)` 事实 id 为核**；**`(ii)` 只作写作纪律**（与 D2/D3 同源）；**`(iii)` 维持 `compare` 现状不扩**（它已覆盖它擅长的那一类） |

| **③** | **CHANGELOG 与既有解析器的关系** | [2]：「同一契约分层加严」+ 上叠「一节恰一条推导式」 · [4]：**「单事实单谓词」**——`**N/N**` 的可推导性**仍归 G-常驻3 独占**，新腿只校**跨档数值** | **采纳 [4]（加性而非重复）**：**G-常驻3 管「节内自洽」，新腿管「跨档同值」，两者 claim 正交**。**⇒ 设计档须给一张「(谓词, 事实) → claim」矩阵**，让评审可核对「两两不相交」 |
| **④** | **单例 id 的口径** | [2]：**任何**带 `id=` 的标记成单例 ⇒ 红 · [4]：**@N 只锁注册事实**，非注册单例**不红** | **采纳 [4] 的不对称**：**「一次事实只出现一次」是常态**，[2] 的普适单例必红会**误伤**它。**⇒ 注册（`require-facts`）才锁次数**；**未注册的单例 id 绿**。**而 [2] 的关切（typo 裂组）由 @N 覆盖**——**两者不冲突，[4] 更准** |
