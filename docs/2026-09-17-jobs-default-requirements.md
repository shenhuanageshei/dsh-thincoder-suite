## §1 总目标（一句话）

**让「长任务」不再被插件自己的 540 秒内部截止掐掉、也不再撞平台 600 秒墙钟连报告一起丢**——把 `eng_coder` 与 `escalate` 的 **dsh 子代理路径默认改成后台派发**（与它们的 codex 后端、以及 advisor/consult 的既有做法一致），**并把这次翻转带来的时序风险用机制封死**。

---

## §2 背景与问题（**带出处与实测量**）

| # | 问题 | 实测 |
|---|---|---|
| **P-1** | **dsh 路径默认同步**：`lib/eng.mjs:936` 是 `if (args?.background === true)` ⇒ **必须显式传才后台**，否则走同步（内部截止 = `budgetCapMs`，缺省 **540s**） | 读源码；`lib/escalate.mjs:425` 同形 |
| **P-2** | **同一插件的其它路径早就不这样了**：codex 后端按 `baseTimeout > budgetCap` **自动后台**（eng codex 缺省 1800s、escalate codex 缺省 600s，都 > 540s）· advisor 按预算自动后台 · consult 无条件后台 ⇒ **dsh 子代理路径是唯一没跟上的那一条** | 纪要 **V12**（**纠正了父侧原先「与 advisor 对齐」的不准确框架**） |
| **P-3** | **同步路径有两种死法，且都是最坏的那种**：① 540s 到点被掐 ⇒ **失败交付**；② 撞平台 600s 墙钟 ⇒ **连交付报告一起丢** | `lib/eng.mjs:932-934` 的注释自认；`budgetCapMs` 540 < 平台 600 是**刻意**留的余量（`lib/advisor.mjs:1686-1688`） |
| **P-4** | **jobs 缺失时的告警只在 console**（`lib/eng.mjs:1025/:1028` · `lib/escalate.mjs:554`）⇒ 翻转后默认走后台，**父代理会以为派了后台、傻等一个永远不会来的通知** = **静默失败**（本仓最忌讳的物种） | 纪要 **D-32-6** |
| **P-5** | ★ **时序风险（会诊两家独立发现）**：父代理不再阻塞 ⇒ **它可能在交付落地之前就跑代码评审**。而重置 `advisorRound`/prior、合并 `touchedFiles` 的簿记发生在 **job settle 的回调**里 ⇒ 早跑的评审**看的文件不对 + prior 被污染 + 那一轮白跑**（状态不会被搞坏——D-10 代际校验兜住——但钱白花） | 纪要 **D-32-1** / **G1** / **V2** |
| **P-6** | ★ **一处会让翻转静默失效的陷阱**：`lib/index.mjs:1011` 把 `args?.background === true` **三态压成二态** ⇒ **不改它，`escalate` 的翻转完全不起作用** | 纪要 **G5④**（**父侧漏看、会诊抓到**） |
| **P-7** | **描述面不准确**：README 的「长任务必须显式传 `background: true`」整节 + schema 描述 + 头注释，在 codex 路径上**本来就是假话**，翻转后对 dsh 也成假话 | 纪要 **D-32-8**（六处清单） |

## §5 边界与登记面

### §5.1 不做项（**七条**）

| # | 不做 | 理由 |
|---|---|---|
| **1** | **不引入新配置键** | N-1；默认翻转靠三态语义即可（会诊两家一致） |
| **2** | **不改 codex 路径的判定** | 它**早已**按预算默认后台（P-2）；碰它 = 无谓的漂移面 |
| **3** | **不改 `budgetCapMs` 缺省** | 纪要 **D-32-4**：抬高 = 消灭 60s 余量、降低 = 无意义 |
| **4** | **不选「jobs 缺失 ⇒ 拒发（fail-closed）」** | 它是 consult 的先例，但会**把 `session-state` / `stages` 拉进授权仪式**（**D-32-5**）；用户已裁定「告警 + 回落」 |
| **5** | **不在本批修「在飞槽位重启失忆」** | 在飞槽位是模块内存态、不落盘；翻转后暴露面变大 ⇒ **登记 R-66**，不修（修它要动持久化面） |
| **6** | **不改 `preset-static` 锁的那句 persona 文案** | 它在翻转后**仍为真**（自动节点还在，只是发生在通知回合）⇒ 动它 = 无谓的授权面扩张 |
| **7** | **不擅自重启 DSH** | 本批改 `lib/**` ⇒ 写进交接页（US-7） |

### §5.2 登记面

**沿用纪要的 R-66 / R-67 / R-68**：**R-66**（在飞槽位内存态 ⇒ 重启失忆，翻转后成常态）· **R-67**（「stage 失败后重派」整体后移一个回合——流程形态变化）· **R-68**（错序评审的**残余**面：护栏只拦 **code 型评审**与 **eng/escalate 槽位**，别的交错组合不在此列）。**本档不新增登记**；设计期若发现新面，写进设计档 **§9.3「诚实残差清单」**（**★ 评审 #8 订正：原指针写「§9.4」，而 §9.4 实为「威胁模型」，语义不对**）。
